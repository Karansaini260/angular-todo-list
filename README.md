# Angular Todo List ✅

A feature-rich **To-do list app** built with Angular, TypeScript and Bootstrap.
Add, edit, categorize and filter tasks with a clean responsive UI.

## ✨ Features
- ➕ Add / ✏️ Edit / 🗑️ Delete todos
- 🏷️ Categories & filters (All / Active / Completed)
- 💾 Local persistence via a small Node server (`server/database.json`)
- 🎨 Bootstrap-based responsive styling
- 🧪 Unit tests (Jasmine/Karma) for services & components

## 🚀 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. (Optional) start the JSON data server
npm run server

# 3. Run the dev server
ng serve
```

Open `http://localhost:4200`.

## 🛠️ Built With
- **Angular 15** · TypeScript · RxJS
- **Bootstrap 5**
- Jasmine / Karma for testing
